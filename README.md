# Jie-Min-Liang
Hi, I'm Jie Min Liang
I am an Honours Computer Science student at Concordia University, interested in medical AI, vision-language model interpretability, and biomedical corpus validation.
My current work focuses on evaluating whether domain-specific biomedical text corpora can improve the interpretability of biomedical vision-language models such as BiomedCLIP. I am especially interested in how semantic descriptions, medical imaging concepts, and model representations can connect in ways useful for explainable AI.
